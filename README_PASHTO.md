# Sana AI — د پیل او خپرولو لارښود

دا د Sana AI د ویب اپ لومړنۍ نسخه ده. دا د موبایل او کمپیوټر په براوزر کې کار کوي. د AI ځوابونه هغه وخت فعالېږي چې د Gemini API کیلي په سرور کې خوندي اضافه شي.

## مهم
- دا فایل لا تر اوسه په عامه انټرنېټ کې نه دی خپور شوی؛ یوازې د ZIP فایل جوړول ژوندی لینک نه جوړوي.
- د Gemini API کیلي هېڅکله په `public` فولډر یا د کاروونکي په براوزر کې مه ږدئ.
- د AI خدمت د وړیا کارولو حدود بدلیدلی شي. مخکې له عامه خپرولو یې بیه او شرایط وګورئ.
- د عامو کاروونکو لپاره د خپرولو پر مهال د محرمیت تګلاره، د ناوړه استعمال مخنیوی او د خدمت د شرایطو رعایت هم مهم دي.

## د Gemini API کیلي
1. د Google AI Studio له لارې API key جوړولو اختیار وګورئ: https://aistudio.google.com/
2. د API د اوسنیو شرایطو او وړیا حدودو لوستل: https://ai.google.dev/gemini-api/docs/pricing
3. د API کیلي یوازې د کوربه‌توب د Environment Variables برخه کې د `GEMINI_API_KEY` په نوم وساتئ.
4. که خدمت د پیسو غوښتنه وکړي، د بیلینګ له فعالولو مخکې یې مه فعالوئ؛ وړیا حدود تایید کړئ.

## د Render له لارې د خپرولو عمومي ګامونه
1. د GitHub حساب جوړ کړئ او د دې پروژې فایلونه په یوه نوي repository کې پورته کړئ.
2. په Render کې د نوي Web Service جوړولو اختیار وټاکئ او repository ورسره وصل کړئ: https://render.com/
3. Build Command تش پرېږدئ یا د ډشبورډ لارښوونې تعقیب کړئ؛ Start Command: `npm start`
4. د Environment Variables برخه کې `GEMINI_API_KEY` اضافه کړئ.
5. Deploy وکړئ. که Deploy بریالی شي، Render به د ویب اپ URL درکړي.
6. لینک په موبایل کې وازمویئ. وړیا hosting ممکن د بې‌فعالیتۍ پر مهال ویده شي او ځینې محدودیتونه ولري.

## په خپل کمپیوټر کې ازموینه
Node.js 18 یا نوې نسخه نصب کړئ، بیا په دې فولډر کې ترمینل خلاص کړئ او ولیکئ:
`npm start`

بیا په براوزر کې خلاص کړئ:
`http://localhost:3000`

که API key نه وي اضافه شوې، اپ به د AI د نښلولو په اړه پیغام ښکاره کړي.
